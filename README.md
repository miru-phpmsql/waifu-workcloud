# waifu-workcloud

Anime-inspired workspace for interacting with coding agents.

Created by zeyy desu.

## Stack
- Next.js
- TypeScript
- React
- OpenAI-ready API routes

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## AI setup

Create a local `.env` file from `.env.example` and add your OpenAI key:

```bash
copy .env.example .env
```

Then fill in:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

If the key is not set, the app stays in demo mode with simulated responses.

## Product direction
Waifu WorksCloud is a modern workspace concept for AI-assisted coding, project orchestration, and collaborative agent workflows.
